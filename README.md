Health–Seatle & King County STI/HIV/HCV epidemiologists.

## Installation

You can install the development version of Misc.SHH.f from
[GitHub](https://github.com/) with:

``` r
# install.packages("pak")
pak::pak("rlechtenberg/Misc.SHH.f")
```
